## Development

Use Node.js 22.12 or later in the Node.js 22 line. Install the locked dependencies with `npm ci` and start the app with `npm run dev`. The app expects its API at `http://localhost:3000`.

Run `npm run build`, `npx playwright install chromium`, and `npm test` to test the production build. The browser tests supply API fixtures.
